## IELTS: Topic words missing from standard lists | B2 | Award | Useful IELTS words with hand-written meanings.
apartment :: noun :: a set of rooms for living in, on one floor of a larger building :: They rent a small apartment near the station.
alcoholism :: noun :: a serious illness in which a person cannot stop drinking alcohol :: Alcoholism can destroy families and careers.
authorities :: noun :: the people or organisations with the power to make decisions or enforce laws :: The local authorities closed the road after the flood.
awareness :: noun :: knowing that something exists or is important :: The campaign raised awareness of the dangers of smoking.
ban :: verb :: to officially forbid something :: The city plans to ban cars from the centre.
begging :: noun :: asking strangers for money or food because you are very poor :: Begging is a common sight in some big cities.
biofuel :: noun :: fuel made from plants or animal waste :: Biofuel can reduce the use of oil.
blogging :: noun :: writing regular posts on a personal website :: Blogging helped her to become a well-known travel writer.
bullying :: noun :: using strength or power to frighten or hurt weaker people :: Schools have strict rules against bullying.
burnout :: noun :: extreme tiredness caused by working too hard for too long :: Long hours can lead to burnout.
carer :: noun :: a person who looks after someone who is ill, old or disabled :: The carer visits my grandmother twice a day.
ceasefire :: noun :: an agreement to stop fighting for a period of time :: The two sides agreed to a ceasefire.
chores :: noun :: small regular jobs around the house :: Children should help with the household chores.
crackdown :: noun :: strong action by the authorities to stop an activity :: There was a crackdown on illegal parking.
criteria :: noun :: standards used to judge or decide something :: Applicants must meet the following criteria.
dairy :: noun :: milk and foods made from milk, such as cheese and butter :: She avoids dairy because it upsets her stomach.
doping :: noun :: using banned drugs to improve sports performance :: Doping has damaged the reputation of many sports.
drilling :: noun :: making holes in the ground or a surface with a special tool :: Drilling for oil in the Arctic is controversial.
enforcement :: noun :: making sure people obey a law or rule :: Stricter enforcement of speed limits could save lives.
errands :: noun :: short trips to do a small job, such as buying something :: I have a few errands to run this afternoon.
extremism :: noun :: holding very strong political or religious beliefs, often leading to violence :: Education can help to prevent extremism.
facilities :: noun :: buildings, equipment or services provided for a particular purpose :: The school has excellent sports facilities.
fiancé :: noun :: a man who has promised to marry someone :: Her fiancé proposed on the beach.
fundraising :: noun :: collecting money for a charity or cause :: The school organised fundraising for the hospital.
goods :: noun :: things that are made to be sold :: The shop sells a wide range of household goods.
graffiti :: noun :: writing or drawings made on walls in public places :: The council spends a lot of money removing graffiti.
heatwave :: noun :: a period of unusually hot weather :: The heatwave lasted for two weeks.
homeschooling :: noun :: teaching children at home instead of at school :: Homeschooling has become more popular in recent years.
hooliganism :: noun :: noisy and violent behaviour by groups of young people, especially at sports events :: Football clubs are tackling hooliganism.
intervention :: noun :: action taken to change what is happening :: Early intervention can help children with learning difficulties.
legislators :: noun :: people who make laws :: Legislators are debating the new tax law.
littering :: noun :: leaving rubbish in public places :: Littering is punished with a fine.
lyrics :: noun :: the words of a song :: I know the lyrics to all her songs.
marginalised :: adjective :: treated as unimportant and pushed to the edge of society :: Marginalised groups often lack access to services.
media :: noun :: television, radio, newspapers and the internet as sources of news :: The media plays a powerful role in shaping opinion.
microfinance :: noun :: small loans and financial services for poor people :: Microfinance helps women start small businesses.
miscommunication :: noun :: a failure to communicate clearly :: The mistake was caused by miscommunication between departments.
overcrowded :: adjective :: containing too many people or things :: The trains are overcrowded during rush hour.
overpopulated :: adjective :: having too many people for the space or resources available :: Some cities have become overpopulated.
penalty :: noun :: a punishment for breaking a rule or law :: The penalty for littering is a fine.
phishing :: noun :: sending fake emails to trick people into giving personal information :: Phishing emails often look like they come from your bank.
radicalisation :: noun :: the process of becoming extreme in political or religious beliefs :: Online radicalisation is a growing concern.
reoffend :: verb :: to commit another crime after being punished :: Many prisoners reoffend soon after release.
resit :: noun :: an exam taken again after failing :: She passed the resit in August.
roadworks :: noun :: repairs being done on a road :: Roadworks have caused long delays.
ruins :: noun :: the broken remains of an old building :: We visited the ruins of an ancient temple.
settings :: noun :: the options on a device or app that you can change :: Check the privacy settings on your account.
sketching :: noun :: making quick, simple drawings :: Sketching is a relaxing hobby.
smoking :: noun :: the habit of breathing in smoke from cigarettes :: Smoking is banned in public buildings.
societies :: noun :: groups of people who share an interest or purpose :: I joined two societies at university.
suburbanisation :: noun :: the growth of residential areas around a city :: Suburbanisation has changed the landscape of many countries.
suicide :: noun :: the act of deliberately ending your own life :: Suicide prevention services receive government support.
trafficking :: noun :: the illegal trade in people, drugs or weapons :: Human trafficking is a global crime.
trawling :: noun :: fishing with a large net dragged along the sea bed :: Bottom trawling damages coral reefs.
truancy :: noun :: staying away from school without permission :: Truancy is a problem in some inner-city schools.
utilities :: noun :: services such as electricity, gas and water :: The rent includes all utilities.
volunteering :: noun :: working without payment to help others :: Volunteering gives young people valuable experience.
weathering :: noun :: the slow breaking up of rock by wind, rain and ice :: Weathering has shaped the cliffs over millions of years.
login :: noun :: the process of entering a username and password to use a system :: Please enter your login details.
offline :: adjective :: not connected to the internet :: You can read the article offline.
e-commerce :: noun :: buying and selling goods over the internet :: E-commerce has changed the way we shop.
